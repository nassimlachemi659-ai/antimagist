WHAT OUR APP ACTUALLY DOES

The Exact Technical Mechanics

We believe in complete honesty. Here is exactly what Antimagist adjusts on your PC and why it reduces latency.

📶
1. Disabling Packet Grouping (TcpNoDelay)

By default, Windows uses Nagle’s algorithm, which delays small network packets to group them together. While fine for web browsing, this causes micro-jitter in online games. Antimagist sets TcpNoDelay=1 and TcpAckFrequency=1 so every game packet is sent immediately.

✓ Verified Windows TCP Optimization
⚡
2. Freeing Inactive Standby Memory

Windows keeps gigabytes of previously closed apps cached in standby memory. When games launch and demand RAM, Windows must abruptly page out data, causing micro-stutters. Antimagist calls the official Windows EmptyWorkingSet API to cleanly free this memory beforehand.

✓ Uses Official Windows Memory Management
🎯
3. P-Core CPU Affinity Pinning

Modern multi-core processors have high-speed physical performance cores and slower efficiency cores. Windows scheduler can move game threads across cores, causing cache thrashing. Antimagist maps your CPU topology and pins game processes to high-priority physical cores.

✓ Eliminates Thread Migration Jitter
🖱️
4. True 1:1 Raw Mouse Tracking

Windows default mouse acceleration dynamically alters crosshair movement speed depending on how fast you swipe. Antimagist resets mouse registry thresholds to 0 for true linear 1:1 raw input. It also disables Xbox GameDVR background screen recording to free CPU cycles.

✓ Muscle Memory Precision & Zero DVR Overhead
🖥️
5. Non-Invasive Transparent In-Game HUD

Most gaming overlays inject DLLs directly into game graphics memory, which can trigger anti-cheat bans. Antimagist's HUD overlay (Ctrl+Shift+O) uses native Windows layered transparency (WS_EX_TOPMOST). It renders strictly as an external desktop window with zero memory hooking.

✓ 100% Safe with VAC, Vanguard & BattlEye
🛡️
6. Complete 1-Click Backup & Restore

Before applying any Windows tweaks, Antimagist automatically saves a timestamped JSON backup of your original settings. If you ever want to revert back to default Windows settings, you simply click "Restore Defaults" for an instant clean rollback.

✓ Total Peace of Mind & Reversibility
